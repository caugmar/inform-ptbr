# Christminster em português brasileiro

Esta versão usa a biblioteca `Portugues` e a gramática `PortuguesG` do
projeto. Os nomes de rotinas, objetos e propriedades do código permanecem
inalterados para preservar a lógica original; textos exibidos e vocabulário
do jogador são traduzidos nos arquivos `.inf`.

Compile com:

```sh
make
```

O resultado é `minster.z8`. Os patches locais de `Parser`, `Grammar` e
`VerbLib` continuam parte do pacote original e são mantidos para a
compatibilidade da conversão Inform 6 de Christminster.
